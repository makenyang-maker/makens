【包内容】
  power-strip.yaml   固件模板 —— 名字全由"编号"自动生成，不用手改
  secrets.yaml       WiFi 配置 —— 换网络只改这个文件
  flash.bat          一键刷机入口（双击）
  flash.py           刷机脚本（查重编号 / 列串口 / 编译 + 刷写）

【一键流程】
  1. 接线 + 进下载模式（见下）
  2. 双击 flash.bat
  3. 输入编号（如 3）→ 脚本自动检查 power-strip-3 是否已被占用
  4. 输入串口号（如 COM3）→ 自动编译 + 串口刷写
  5. 刷完：断电 -> 拆 IO0 跳线 -> 重新上电
  6. 设备自动连 WiFi，HA 自动发现"智能插板3"，确认即可

  生成的名字（以编号 3 为例）：
    设备名 power-strip-3 / HA 设备"智能插板3" / 开关"插座3"
    按钮"插座按钮3" / AP 热点"智能插板3 AP"（密码 12345678）

【一、准备】
  1. USB-TTL 适配器（CH340 / CP2102 等）
     !! 必须支持并设置为 3.3V 电平，5V 会烧 ESP8266
  2. 插上电脑，设备管理器确认出现 COM 口
  3. 编号规则：HA 里已有的智能插板/智能插板2 占用 1/2，
     新设备从 3 开始

【二、接线（只接 3 根信号线！）】
  插座插上 220V 供电（板载 AMS1117 自产 3.3V），
  TTL 适配器绝对不要往板子上接任何电源线：

      TTL TX   ->   模组 RX 针脚（ESP-01 插座）
      TTL RX   ->   模组 TX 针脚
      TTL GND  ->   模组 GND

  !!! TTL 的 3.3V / 5V / VCC 一律悬空（双电源冲突会出事）
  !!! 接反了就互换 TX/RX 再试（最常见错误）

【三、进下载模式（每次刷机都要）】
  1. 杜邦线：ESP-01 插座的 IO0 针脚 -> GND
  2. 插座上电（此时 ESP8266 进入串口刷写模式）
  3. 开始刷写后 IO0 跳线就可以拆了

【四、改 WiFi（换网络时）】
  编辑 secrets.yaml：
      wifi_ssid: "新的WiFi名"
      wifi_password: "新的密码"
  重新刷一次即可。刷完如果连不上，设备会开热点
  "智能插板N AP"（密码 12345678），浏览器 192.168.4.1 可改。

【常见问题】
  * Connecting... 一直点号
      -> 设备没进下载模式：确认 IO0 接 GND 后重新上电再刷
      -> 460800 连不上不用管，会自动降到 115200 重试
  * FileNotFoundError: ... firmware.bin（刷写一开始就报错退出）
      -> upload 前必须先 compile（flash.py 已内置两步；手动刷的话
         先跑 esphome -s dev_num N compile power-strip.yaml 再 upload）
  * 提示"编号已存在于网络"
      -> 如果就是要重刷这台设备（如改 WiFi），选 y 继续即可；
         全新设备选 n 退出换编号
  * 刷完WiFi灯（板上LED1）不亮
      -> 等半分钟重连；还不行检查 secrets.yaml 的 WiFi 配置
  * 按钮里的蓝灯不亮
      -> v2 固件已内置修复（GPIO2 常低使能板上 RF 芯片 XN297L，
         上电瞬间采样，低电平有效），刷完通电即亮
      -> 若还不亮：确认用的是本包 power-strip.yaml v2，
         不要删掉固件里那几个 internal 的 RF 使能开关
      -> 注意：蓝灯只会"通电常亮"，按按钮关断时不灭
         （那需要原厂 UART 协议，出厂代码已被擦除，无法复刻）
  * 换电脑用
      -> 装 Python + esphome（pip install esphome），
         改 flash.py 顶部的 PYTHON 路径

【刷机后验证】
  * WiFi 灯（LED1）常亮 = 已联网
  * 按键蓝灯常亮 = XN297L 使能正常（v2 固件自带）
  * HA 里出现"智能插板N"，开关"插座N"能控制通断
  * 物理按钮每按一次通断切换
  * 建议马上在路由器给它的 MAC 做静态 IP 绑定
